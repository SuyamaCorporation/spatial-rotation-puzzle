# Spatial Rotation Puzzle

**Category:** Puzzle / Spatial Reasoning

A 3D mental rotation challenge where players rotate polyhedra (cube, L-shape, T-tetromino) to match a target orientation. Uses a custom 3D rendering engine with painter's algorithm and Phong-style lighting. Controls via on-screen buttons or arrow keys (Q/E for Z-axis roll). Tracks match percentage, rotation count, time, and cumulative score across progressive levels.
